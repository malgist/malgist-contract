SECURITY FEATURES
================================================================================
✓ Chain ID enforcement (5003 only)
  - Prevents accidental mainnet deployment
  - Reverts with NotTestnet error on other chains

✓ Per-address rate limiting (24h default)
  - Prevents spam and abuse
  - Configurable by admin
  - Independent for each user

✓ Maximum claim amount (10k USDC)
  - Prevents vault griefing
  - Configurable by admin
  - Enforced in claim() function

✓ Reentrancy protection
  - NonReentrant decorator on claim()
  - Checks-effects-interactions pattern
  - State updated before external calls

✓ Minter authorization (MockUSDC)
  - Only authorized addresses can mint
  - Faucet added during deployment
  - Prevents unauthorized token creation

✓ Custom errors
  - Gas efficient error messages
  - Type-safe error handling
  - Clear error semantics
